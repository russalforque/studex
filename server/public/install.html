Install Studex on Android

Steps

  1. On your phone, open the Download for Android link from your purchase email or payment page.
  2. When the download finishes, tap the file Studex-x.y.z.apk (or find it in the Files app under Downloads).
  3. The first time, Android says installs from your browser aren't allowed. Tap Settings, turn on Allow from this source, then go back.
  4. Tap Install, then Open.
  5. Tap Activate Studex and enter your license code. Done: Studex now works offline.

You can turn Allow from this source off again afterwards. It's only needed while installing.

Updating

Download the new version the same way and install it over the old one. Your data and activation stay in place, because every Studex release is signed with the same key. Make a backup first anyway (Settings → Data → Back up); it's a good habit.

Check the file (optional)

Every release lists its SHA-256 checksum above. On a computer: certutil -hashfile Studex-x.y.z.apk SHA256 (Windows) or shasum -a 256 Studex-x.y.z.apk (Mac/Linux). The result must match exactly.

Troubleshooting

"App not installed" or "package conflicts with an existing package"

A Studex build from somewhere else is installed. Back up your data in that copy first, uninstall it, then install ours and restore the backup.

"There was a problem parsing the package"

The download didn't finish. Delete the file and download it again on Wi-Fi. Studex needs Android 7.0 or newer.

Play Protect warns about the app

Play Protect may ask about apps installed from outside the Play Store. Check that the file came from this website (and its checksum matches), then choose Install anyway.

Installs are blocked by my phone's settings

Some phones (Xiaomi, Oppo, Vivo, Huawei) have an extra security switch: Settings → Security (or Privacy) → Install unknown apps. Allow it for your browser or Files app.

Activation says I'm offline

Activation needs the internet once. Connect to Wi-Fi or mobile data, then try again. After that you can use Studex offline.

Activation says Studex is active on another device

Tap Restore purchase and enter your purchase email to move Studex to this phone. You don't need the old phone.
